# Examples

Two complete, annotated CLI Schema documents are included in the repository.

## GitHub CLI (`gh`)

[GitHub CLI example walkthrough](gh-cli.md) — covers the `gh` CLI with authentication, the `repo` and `auth` namespaces, destructive command intent, `confirmationSkip` flags, and structured output declarations.

Raw JSON: [`spec/v1/examples/gh.cli-schema.json`](https://github.com/cli-schema/cli-schema/blob/main/spec/v1/examples/gh.cli-schema.json)

## Git

[Git example walkthrough](git.md) — covers `git` with flat top-level commands, `dryRun` flags on `commit` and `push`, dangerous command tags on `reset`, structured output on `log`, and repeatable flags.

Raw JSON: [`spec/v1/examples/git.cli-schema.json`](https://github.com/cli-schema/cli-schema/blob/main/spec/v1/examples/git.cli-schema.json)
